# Todo REST API

A RESTful To-Do API built using PHP OOP, MySQL, and PDO.

## Features

- Create, read, update, and delete tasks
- API versioning (v1)
- Filter tasks by status, priority, and due date
- Search tasks by title or description
- Sorting and pagination
- JSON responses and input validation

## Technologies

- PHP
- MySQL
- PDO
- Composer
- Apache (XAMPP)
- Thunder Client (VS Code extension)

## Installation

1. Clone or download the repository.
2. Run `composer install`.
3. Create a MySQL database named `todo_api`.
4. Import the database schema.
5. Configure the `.env` file.


## Base URL

http://localhost/todo-api/public/api/v1

## Testing

Use Thunder Client in VS Code to send HTTP requests.

See [API Documentation](docs/API.md) for endpoints and examples.
